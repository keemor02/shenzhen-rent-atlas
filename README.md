# 深圳租房探索雷达（V2 轻量离线原型）

一个面向深圳租客的**离线单文件找房与议价探索工具**。双击 [index.html](index.html) 即可在电脑或手机浏览器直接使用，无需安装软件、无需联网或注册账号。

---

## 用「电商独立站」的思路看懂项目目录

整个 V2 项目彻底把**“商品数据”**和**“页面模板”**分开，体量极轻（零第三方运行库、无 `node_modules`）：

| 目录 / 文件 | 独立站类比 | 你平时用来干嘛 |
| --- | --- | --- |
| `sources/v2/` | **商品数据表** | 放各走廊分形态租金带（`corridor-rents.json`）与扩区核验设施（`facilities-extra.json`），全是人话 JSON |
| `v2/` | **网站主题模板** | 只留 6 个小文件：`template.html`、`app.css`、`store.js`、`engine.js`、`map.js`、`ui.js` |
| `tools/` | **自动打包与采集脚本** | `build_v2_data.cjs`（汇总数据）、`build_v2.cjs`（生成单文件）、`sync_osm.cjs`（拉取 OSM 新轮廓/POI） |
| `tests/v2.test.cjs` | **发布前自动体检** | 自动检查数据完整性、议价雷达、双地通勤、老收藏兼容与打包一致性 |
| `index.html` | **最终发布的成品页** | 双击直接试玩，可发到手机离线看房用 |

## 日常迭代只需记住这 3 条命令

在项目根目录打开终端运行（仅需本机已装好的 Node.js）：

1. **改完数据或代码后，一键重新生成离线地图**：
   ```bash
   node tools/build_v2_data.cjs && node tools/build_v2.cjs
   ```
2. **发布前自动体检（检查有没有改坏）**：
   ```bash
   node tools/build_v2.cjs --check && node --test tests/v2.test.cjs tests/phase2-3-4.test.cjs tests/transport.test.cjs
   ```
3. **保存一个安全存档点（随时可回退）**：
   ```bash
   git add -A && git commit -m "说明你这次改了什么"
   ```

## V2 核心能力一览

1. **探索与议价（主视角）**：按「城中村 / 老小区 / 电梯小区 / 公寓·保租房」多选过滤，告别把城中村和商品房混成一锅粥；一键切换 **「议价雷达」**，自动综合大厂外迁/保租房分流 + 同通勤圈（±10 分钟）同形态中位价差 + 商圈同比。
2. **双地通勤**：同时设定「当前工作地」与「潜在下一份工作地」，支持一键切换 **街区地图 / 10 分钟等时时间圈**。
3. **宜居与避坑**：覆盖 55 处官方核验设施（西乡、西丽、新安、粤海、南头）与 7 条公开环境/噪声/施工避坑点。
4. **看房清单**：自动无缝继承旧版收藏与看房手记，支持最多 4 处候选并排横向对比与 JSON 一键备份恢复。
